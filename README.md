# Electric Vehicle Analysis – Tableau Dashboard

An interactive Tableau dashboard designed to analyze electric vehicle (EV) adoption trends, vehicle distribution, manufacturer performance, and eligibility patterns across the United States.

---

## 📌 Project Overview

This project provides a comprehensive analysis of electric vehicle population data, focusing on:

- EV adoption growth trends
- BEV vs PHEV distribution
- State-wise EV concentration
- Top manufacturers and models
- CAFV eligibility status
- Electric range performance

The dashboard supports EV market analysis, sustainability planning, and automotive trend forecasting.

---

## 📊 Key KPIs

- **Total Vehicles:** 150,422  
- **Average Electric Range:** 67.83 Km  
- **Total BEV Vehicles:** 116,750 (77.61%)  
- **Total PHEV Vehicles:** 33,672 (22.39%)

---

## 🔍 Dashboard Features

### 1️⃣ EV Growth Trend
- Electric vehicles registered by model year
- Rapid growth post-2018
- Peak registrations observed in recent years

### 2️⃣ Geographic Distribution
- State-wise vehicle distribution (US Map)
- High EV concentration in select states
- Regional adoption pattern insights

### 3️⃣ Manufacturer Analysis
- Top 10 vehicle manufacturers
- Tesla leading EV market share
- Comparative analysis of top brands

### 4️⃣ Model-Level Analysis
- Top vehicle models by volume
- Percentage contribution of each model
- BEV vs PHEV segmentation

### 5️⃣ CAFV Eligibility Analysis
- Eligible vs Non-Eligible vs Unknown
- Policy impact insights
- Environmental compliance distribution
